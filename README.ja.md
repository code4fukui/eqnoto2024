# eqnoto2024

令和6年能登半島地震（2024年1月1日〜2日）における気象庁（JMA）の潮位データを可視化するWebアプリケーションです。このツールは潮位の経時変化をプロットし、主要な地震イベントや津波警報をグラフ上に注釈として追加することで、災害が海面に与えた影響を時系列で明確に示します。

## デモ

**https://code4fukui.github.io/eqnoto2024/**

## スクリーンショット

本アプリケーションは、選択した観測所（デフォルトは能登と七尾）の潮位を時系列の折れ線グラフで表示します。グラフ上の垂直線は、主要な地震の発生時刻と津波警報レベルの変更タイミングを示しています。グラフの上部には、利用可能な潮位観測所の位置を示すインタラクティブな地図があり、観測所をクリックすることでグラフへのデータの追加・削除が可能です。

## 機能

- **時系列の可視化:** 2024年1月1日〜2日の能登半島周辺の気象庁観測所の潮位データをプロットします。
- **イベントの注釈:** グラフのタイムライン上に、以下の重要なイベントを重ねて表示します。
  - 主要な地震（M5.7以上）のマグニチュードと震度。
  - 津波警報の発令、切り替え（大津波警報→津波警報→津波注意報）、および最終的な解除。
- **インタラクティブな地図:** 地図上の気象庁の観測所をクリックすることで、グラフにデータを動的に追加または削除できます。
- **データの比較:** 1つのグラフ上で複数地点の潮位変化を簡単に比較できます。

## 使い方

静的なWebアプリケーションであり、ビルドプロセスは不要です。

1. リポジトリをクローンします:
    ```bash
    git clone https://github.com/code4fukui/eqnoto2024.git
    ```
2. Webブラウザで `index.html` を開きます。

## 技術スタック

本プロジェクトは、Vanilla JavaScriptとHTMLで構築された静的なWebアプリケーションです。以下の主要なライブラリを使用しています。

- **[ApexCharts.js](https://apexcharts.com/):** インタラクティブな時系列グラフの作成。
- **[DateTime.js](https://js.sabae.cc/DateTime.js):** 日時のパースを処理する軽量ライブラリ。
- **[csv-map.js](https://github.com/js-sabae/csv-map):** 観測所のインタラクティブな地図を表示するWebコンポーネント。

## データソース

本アプリケーションは、気象庁（JMA）のオープンデータを利用しています。

- **潮位データ:** 気象庁の[潮位観測情報](https://www.jma.go.jp/bosai/tidelevel/)から取得し、[tidelevelリポジトリ](https://github.com/code4fukui/tidelevel)で集約されたもの。
- **地震情報:** 気象庁の[地震情報](https://www.data.jma.go.jp/multi/quake/index.html?lang=jp)から取得。
